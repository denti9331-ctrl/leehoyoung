# DARK FAIRY TALE

GitHub 업로드용으로 정리한 정적 웹사이트입니다. 이 폴더의 내용을 저장소 최상위에 올리면 됩니다.

메인: index.html / 네 권의 책: book-library/index.html / 빨간모자: redridinghood/index.html

## 적용한 최적화

- 백업, 미사용 모델, 이전 시안과 중복 이미지 제외
- 배경·표지 이미지를 WebP로 변환하고 자바스크립트에 포함됐던 큰 이미지 분리
- Three.js를 두 화면에서 공유하고 코드 압축
- 신전 모델에 좌표·인덱스를 유지하는 Meshopt 압축 적용
- 중복 폰트를 하나로 합치고 현재 화면에 필요한 글자만 WOFF2로 저장
- 꽃잎·비눗방울을 알파 채널이 있는 720p WebM으로 압축
- 책·이야기 화면의 CSS/JS 요청을 묶고, 화면 밖의 책 렌더링 정지
- 책 화면으로 직접 돌아올 때 신전 모델 로딩 지연

## 미리보기와 업로드

현재 로컬 최적화 미리보기는 http://127.0.0.1:4175/ 입니다.

GitHub Pages에 올릴 때는 이 폴더 안의 index.html과 assets, book-library, forest-entry, redridinghood 등을 함께 업로드하세요. HTML을 파일로 직접 여는 대신 HTTP 서버나 GitHub Pages를 사용해야 3D 모델이 표시됩니다. 별도 빌드 과정이나 Node 의존성 설치 없이 배포할 수 있습니다.

폰트는 현재 웹사이트 문구를 기준으로 글자를 추렸습니다. 나중에 새로운 한글 문구를 추가할 때는 원본 폰트에서 필요한 글자를 다시 포함해 주세요. 편집용 원본 프로젝트는 Desktop/fairytale-web에 보존돼 있습니다.

## 확인한 동작

신전 3D 모델·책 선택·책 호버·꽃잎·비눗방울 인트로에서 루프 전환·빨간모자 이야기 장면을 확인했습니다. 모델 압축 데이터의 복원 결과를 검사했고, HTML/CSS 및 모델 텍스처 참조 파일과 파일명 대소문자도 검사했습니다.
